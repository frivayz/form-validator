# Задача: добавить валидацию номера телефона

## Что нужно сделать

Добавить в модуль `form_validator` функцию `validate_phone`, которая проверяет
номер телефона в российском и международном формате.

## Зачем это нужно

В форме регистрации поле «Телефон» сейчас принимает любую строку, включая
`"abc"` и `"123"`. Из-за этого в базу попадают заведомо некорректные номера,
а служба поддержки не может связаться с пользователем.

## Критерии приёмки

- [x] Принимаются номера в формате `+7 (999) 123-45-67`, `8-999-123-45-67`,
      `+7 999 123 45 67`
- [x] Результат нормализуется к виду `+79991234567`
- [x] Пустая строка, `None`, буквы и слишком короткие номера вызывают `ValidationError`
- [x] Функция экспортируется из пакета `form_validator`
- [x] Написаны юнит-тесты на все случаи, включая граничные

## Дополнительный контекст

- Обсуждение в чате команды: поддержка просит единый формат хранения — `+7XXXXXXXXXX`
- Смежная задача: валидация email уже реализована (см. `validators.py`)
